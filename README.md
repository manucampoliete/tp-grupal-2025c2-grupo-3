## Instalación

1. Clonar este repositorio

2. Moverse adentro del repositorio 

```bash
cd tp-grupal-2025c2-grupo-3
```

3. Ejecutar el instalador

```bash
./installer.sh
```

o bien 

```bash
bash installer.sh
```

4. Salir del repositorio

```bash
cd ..
```

5. Eliminar el repositorio

```bash
rm -r tp-grupal-2025c2-grupo-3
```
